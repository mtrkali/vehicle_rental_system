project name: vehicle_rental_system
Live_link: https://l2-assignment-2-gamma.vercel.app


--Technology stack & Features -

    Technology stack:
     ** Node.js + TypeScript
     ** Express.js (web framework)
     ** PostgreSQL (database)
     ** bcrypt (password hashing)
     ** jsonwebtoken (JWT authentication)

   Features:
    ** role based access
    ** protected api
    ** simple rental system
    ** realtime data management

--Setup & Usage -
   Setup: 
     ** git clone https://github.com/mtrkali/vehicle_rental_system.git
     ** npm install

  Usage:
    ** Enter on terminal - "npm run dev"
    ** call api from a browser
